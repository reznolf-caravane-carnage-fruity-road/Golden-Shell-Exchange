# Caravan Carnage: Fruity Road — icon exports

PNG copies extracted from the game's `data.unity3d` with UnityPy. These are the
raw sprites; they keep their original transparency and resolution.

## `shells/` (12 files)

| File | Notes |
|---|---|
| `golden_shell.png` | **Used by the mod** for the exchange button and the rate row |
| `Gold_shells_0.png`, `Gold_shell_x2_0.png` | "Gold shells" reward art |
| `Shop_shell_1.png` / `shop_shell_1.png` | Large shop shell art (1452×1421) |
| `Shell1..4.png` | Smaller shell variants |
| `50shells.png` | 50-shell pack |
| `shell_pickup_fx.png` | Pickup effect |
| `Shell_cash_multiplier.png` | Shell/cash multiplier icon |
| `grenadeshellls.png` | Grenade-shell projectile |
